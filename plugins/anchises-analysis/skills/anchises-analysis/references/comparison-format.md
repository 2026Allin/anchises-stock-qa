# Company comparison answer format

Lead with a compact comparative conclusion. Then use only the sections needed
for the request:

1. **Comparison basis** — companies, listings, dimensions, evidence dates, and
   any inferred definitions.
2. **Side-by-side evidence** — a compact table when the same fields map cleanly
   across companies.
3. **Interpretation** — relative strengths, weaknesses, trade-offs, and
   non-comparable items.
4. **Catalysts and risks** — only when requested or material to the comparison.

Use one row per comparison dimension rather than one mini report per company.
Short company context may precede the table, but it must support the relative
analysis.

Place source links next to material web claims. For structured market measures,
state the data date or range, filters, missing values, and whether all
companies share the same period. Separate web-sourced narrative from Anchises
structured market data.

Do not silently omit companies, fabricate an overall winner, or hide that
inputs are unavailable or not comparable.
